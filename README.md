## Modelo de Banco de Dados (ERD)
O repositório contém o projeto prático da disciplina de Business Intelligence II do CEUB. O objetivo da atividade é aplicar conceitos de modelagem construindo um modelo Star Schema a partir de uma tabela desnormalizada com dados de matrículas e cursos da Escola Virtual de Governo (EVG).

# Modelagem de Dados: 
Transformação de uma tabela única (One Big Table) em Tabela Fato e Tabelas Dimensão (ex: Alunos, Cursos, Turmas).

# Ferramentas: 
Power BI e Power Query para tratamento e visualização , e DrawDB para desenho de banco de dados.
